
# Animal Bites Analysis Project

This project explores animal bite data from Louisville Metro Public Health, using summaries and visuals to uncover trends and patterns in bite incidents by species, location, and severity.

---

## Data Source

* Dataset: https://www.kaggle.com/datasets/rtatman/animal-bites
* Date Accessed: January 29, 2026
* Description: Attributes of animal bite incidents reported to and investigated by Louisville Metro Department of Public Health and Wellness.

## Key Findings

* Most bites from dogs (81%), followed by cats only representing 18% of all incidents.
* All other species only account for approximately 1% of all incidents.
* Data suggests that bite frequency correlates with how much time humans spend around animals. Dogs and cats are common pets, while wild life and humans are not in frequent contact.
